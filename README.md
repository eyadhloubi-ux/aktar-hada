# مين أكتر حدا؟ — قعدة رواق

لعبة سهرة للشلة والعيلة: سؤال بيطلع عالكل، كل واحد بيصوّت من موبايلو، والريس بيكشف النتيجة قدّام الجميع.
إعداد م. إياد حلوبي · صار بدها قعدة.

---

## شو في بهالحزمة

```
qa3da-aktar-hada/
```

## كيف بتشتغل

- الريس بيفتح الرابط ← «افتح قعدة جديدة» ← بيطلع QR وكود من 5 أحرف.
- الكل بيمسح الـQR (أو بيكتب الكود) وبيفوت باسمه وصورته (أو سيلفي من الكاميرا)، وبيختار شب أو صبية.
- **إعدادات الريس قبل البداية:** كم سؤال (10 / 15 / 20 / 30 / كلهن من 40)، أو يختار الأسئلة بإيده، ومؤقت للجواب (بلا / 15 / 30 / 45 / 60 ثانية)، وأسئلة من عندهن.
- بكل سؤال الريس بيختار: **اكشف**، أو **الجاي بلا كشف** (بتنحفظ للآخر)، أو **مرّر** (بينمسح كأنو ما انسأل)، و**سؤالك** و**+15ث**.
- **المؤقت:** لما يخلص الوقت التصويت بيتسكّر، واللي اختار وما ثبّت بينبعت صوته لحاله.
- **إدارة اللاعبين** (أيقونة الأشخاص فوق): الريس بيعدّل أي اسم، وبيطلّع حدا (وما بيقدر يرجع)، أو بيسلّم الريسة لحدا تاني. وكل لاعب بيقدر يعدّل اسمه بشاشة الانتظار.
- **إذا طلع الريس:** اللعبة ما بتوقف. بعد 45 ثانية بيطلع عند الكل زر «خليني أنا الريس»، وأول واحد بيكبسه بيكمّل من نفس المكان. وإذا رجع الريس القديم بيصير لاعب عادي.
- بالآخر: كشف دفعة وحدة أو **حفلة توزيع الألقاب**. ونوع القعدة: شلة، عيلة… أو **«غير شي»** بيكتبوه هنن (مثلاً: صحاب الجامعة).
- النتيجة النهائية حسب الشخص وكل الأسئلة بتفاصيلها، بدون ما يبين مين صوّت لمين.
- صورة الستوري حسب الشخص، والريس بيختار الألقاب اللي بتطلع فيها.
- **«كيف منلعب؟»** (أيقونة الـ؟ فوق): تعليمات اللعبة للكل وللريس.
- اللعبة بتنزل كتطبيق، وإذا انقطع النت أو انسكّرت الصفحة ورجع فتح الرابط، كل واحد بيرجع لمكانه.
- لتجربة اللعبة لحالك: زيد `?demo=1` بآخر الرابط.

## 1) الرفع على GitHub

**من المتصفح (الأسهل):**
1. افتح github.com ← **New repository** ← سمّيه مثلاً `qa3da-aktar-hada` ← خليه **Private** أو Public (متل ما بتحب) ← **Create repository**.
2. اضغط **uploading an existing file**.
3. فك ضغط الملف عندك، واسحب **محتوى** المجلد `qa3da-aktar-hada` (الملفات والمجلد `public`) لصفحة الرفع. انتبه يكون `server.js` و `package.json` بأول الريبو، مو جوّا مجلد تاني.
4. **Commit changes**.

> ملاحظة: الملف `.gitignore` بيبدأ بنقطة وممكن يكون مخفي عندك، عادي إذا ما انرفع.

**أو من التيرمنال:**
```bash
cd qa3da-aktar-hada
git init && git add . && git commit -m "مين أكتر حدا؟"
git branch -M main
git remote add origin https://github.com/<اسمك>/qa3da-aktar-hada.git
git push -u origin main
```

## 2) النشر على Render

**الطريقة الأسرع (Blueprint):**
1. ادخل render.com وسجّل بحساب GitHub.
2. **New +** ← **Blueprint** ← اختار الريبو ← **Apply**.
3. Render بيقرأ `render.yaml` وبيعمل كل شي لحاله. بعد دقيقتين بيعطيك رابط متل: `https://qa3da-aktar-hada.onrender.com`

**أو يدوي (Web Service):**
- **New +** ← **Web Service** ← اختار الريبو
- Runtime: **Node** · Region: **Frankfurt**
- Build Command: `npm install --omit=dev`
- Start Command: `npm start`
- Health Check Path: `/healthz`
- Environment ← زيد `STATS_KEY` = أي كلمة سر طويلة بتختارها

## 3) الإحصائيات

- افتح: `https://<رابطك>/stats?key=<STATS_KEY>`
- بتلاقي قيمة `STATS_KEY` بـ Render ← الخدمة ← **Environment**.
- بتعرض: الزيارات، القعدات اللي انفتحت، الألعاب اللي بلّشت وخلصت، عدد اللاعبين، الجولات، أكتر الأسئلة لعباً، نوع المجموعة (شلة/عيلة…)، وعدد اللاعبين بالقعدة، ورسم لآخر 14 يوم.
- **مهم:** على الخطة المجانية، الأرقام بتنحفظ بملف وبتضيع كل ما Render يعيد تشغيل الخدمة. لتنحفظ للأبد:
  1. **New +** ← **PostgreSQL** (اسمه مثلاً `qa3da-db`، نفس المنطقة Frankfurt).
  2. انسخ **Internal Database URL**.
  3. بالخدمة ← **Environment** ← زيد `DATABASE_URL` = الرابط اللي نسخته ← Save.
  السيرفر بيكتشفها لحاله وبيصير يحفظ فيها.

## 4) أشياء لازم تعرفها قبل أول سهرة

- **الخطة المجانية بتنام:** إذا ما حدا فات عالرابط شي ربع ساعة، الخدمة بتنام، وأول فتحة بعدها بتاخد تقريباً دقيقة. فخلي الريس يفتح الرابط **قبل** ما يطلب من الشلة يمسحوا الـQR. للاستخدام الجدي (ريلز وجمهور) الأفضل الخطة المدفوعة الأرخص لأنها ما بتنام.
- **رابط الـBio:** حط رابط Render مباشرة، أو بعدين اربط دومين خاص (Settings ← Custom Domains).
- **أي تعديل:** عدّل الملف على GitHub ← Render بينشر النسخة الجديدة لحاله.
- **حد اللاعبين:** 40 لاعب بالقعدة (بتتغير من `MAX_PLAYERS` بالـEnvironment).
- **وقت انتظار الريس:** 45 ثانية قبل ما يقدر حدا تاني ياخد الريسة (بتتغير من `HANDOVER_MS` بالملي ثانية).
